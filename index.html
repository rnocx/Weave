Weave

Connect to your WeeChat relay

Advanced

Your settings and password stay in this browser. This site only delivers the app: it stores nothing and never sees your chat.

Your relay needs
  1. Secure WebSocket (wss://) with a certificate your browsers trust: /relay add tls.api 9000, or a reverse proxy or Tailscale Serve in front of a plain api relay. This page uses HTTPS, so browsers block plain ws://, and self-signed certificates must be accepted on every device.
  2. To be reachable from this device: over the internet, or on the same VPN or tailnet. Relays on private addresses may make the browser ask for local-network access.
  3. To allow this page:
    4. 
        
  4. relay.network.allowed_ips to include your devices, or 127.0.0.1 when a proxy sits in front.
    5. 
        
  5. A strong password:
    /set relay.network.password "a-strong-password"
    It's sent hashed when the relay supports it.
    6. 
      

      

    

    

      
Relay setup (run inside WeeChat)


/set relay.network.password "your-password"
/relay add tls.api 9000   # or: /relay add api 9000

About LitterboxFree, anonymous, temporary hosting by catbox.moe. Anyone with the link can download the file until it expires, and uploads can't be deleted early. Up to 1 GB per file.

About tmpfiles.orgFree, anonymous, temporary hosting by tmpfiles.org. The link opens a download page; anyone with it can download the file until it expires, and uploads can't be deleted early. Up to 100 MB per file.
